# HandeMade: Made for Hande

HandeMade, alerjen profili ve evdeki malzemelere göre tarif fikirleri sunan mobil öncelikli bir PWA prototipidir.

Bu depo GitHub Pages üzerinden iPhone'da Safari ile açılacak ve Ana Ekrana Eklenebilecek şekilde hazırlanmıştır.

> Not: Bu prototip tıbbi güvenlik garantisi vermez. Ciddi gıda alerjilerinde ürün etiketleri ve çapraz bulaşma uyarıları ayrıca kontrol edilmelidir.
